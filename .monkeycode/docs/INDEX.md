# 项目文档索引

## 项目概览

MeowDebateAssistant 是一个面向中文竞技辩论场景的实时辩论辅助程序。当前仓库已经完成第一阶段骨架搭建，建立了桌面端入口、共享核心模块、运行时事件总线、模块注册器以及 CI 校验基础。

## 文档列表

- `ARCHITECTURE.md`：系统分层、目录结构与当前骨架说明。
- `INTERFACES.md`：当前共享核心暴露的运行时接口与模块边界。
- `DEVELOPER_GUIDE.md`：本地开发、验证与后续扩展方式。
